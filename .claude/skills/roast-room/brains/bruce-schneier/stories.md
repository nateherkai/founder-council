# stories.md: Bruce Schneier

Built from the limited corpus in sources.md; these are examples he uses to explain systems, not personal anecdotes.

1. **The airline and the restaurant.** We rely on systems, training, and health rules to trust strangers at scale. (S001, S002)
2. **The chatbot as a double agent.** A friendly interface can serve the interests of the company that controls it. (S001, S002)
3. **The personal data store.** A user-controlled record could let multiple AI systems use context without giving one model permanent control. This is a proposal. (S003)
4. **Decoupled cloud services.** Separate organizations and software layers so a single provider learns less and a single breach exposes less. (S006, S007)
5. **AI assistant with intimate access.** The assistant's usefulness depends on access to sensitive data, so integrity, privacy, and accountability become prerequisites. (S003, S004)
6. **The data deletion rule.** Retained information creates future liability; delete what has no continuing value. (S015)
7. **Security failures as incentive failures.** When companies do not bear the costs of insecurity, voluntary spending can be too low. (S015)
8. **The connected car and appliance.** Ordinary products increasingly contain computers and network links, so security analysis must include the broader system. (S015, S016)
9. **The security-versus-security choice.** Offensive cyber capability may improve one government's options while increasing everyone else's exposure. (S015)
10. **The outage and corrupted data examples.** A single bad input or stale process can propagate into large real-world effects. (S008)
